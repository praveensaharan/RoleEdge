# Demo album

Synthetic pictures for the Google Photos demo account (`roleedge.errands.demo_accounts`), made on 2026-11-03:

* photos drawn with Meta's Muse Image (`muse-image-1.0`), photorealistic, with no faces (people only from behind or far
  away) and no real people or private places;
* documents (a Sendai city notice, a school letter, a trip confirmation, a school flyer) rendered from HTML, with the
  same synthetic details the demo mailbox uses, so the reader reads real dates off the page.

`../shop/` holds three product shots (cardigans) for the Rakuten order scene on the home page, drawn the same way.
